mininumpy.array.matmul_flat_2D_strassen(A, B, n, p, m)[source]

Perform 2D matrix Strassen multiplication in flattened form.

This computes C = A @ B, where:

  • A is a (n * p) matrix stored row-major in a flat list.

  • B is a (m * p) matrix stored row-major in a flat list.

  • The result C is an (n * m) matrix stored row-major in a flat list.

Parameters:

  • A (list[float]) – Flattened list representing an (n * p) matrix.

  • B (list[float]) – Flattened list representing a (p * m) matrix.

  • n (int) – Number of rows in A.

  • p (int) – Number of columns in A (and rows in B).

  • m (int) – Number of columns in B.

Return type:

list[float]

Time complexity: O(k ^ log2(7)) where k = 2 ^ int(log2(max(n, p, m))) Space complexity: O(k ^ 2)

Returns: Flattened list representing the (n * m) result matrix.

mininumpy.array.matmul_flat_2D(A, BT, n, p, m)[source]

Perform 2D matrix naive multiplication in flattened form.

This computes C = A @ B, where:

  • A is an (n * p) matrix stored row-major in a flat list.

  • BT is the transpose of B, i.e. a (m * p) matrix stored row-major in a flat list. (so each row of BT corresponds to a column of the original B).

  • The result C is an (n * m) matrix stored row-major in a flat list.

Parameters:

  • A (list[float]) – Flattened list representing an (n * p) matrix.

  • BT (list[float]) – Flattened list representing a (m * p) matrix (transpose of B).

  • n (int) – Number of rows in A.

  • p (int) – Number of columns in A (and rows in B).

  • m (int) – Number of columns in B (rows in BT).

Return type:

list[float]

Time complexity: O(n * m * p) Space complexity: O(n * m)

Returns: Flattened list representing the (n * m) result matrix.

__matmul__(other)[source]

Perform matrix multiplication (the @ operator) between two Array objects.

This supports batched matrix multiplication: - If self has shape (…, n, p) and other has shape (…, p, m),

the result will have shape (…, n, m).

  • The leading dimensions (...) must match.

Parameters:

other – Right-hand side operand. Must be an Array with compatible dimensions (self.shape[-1] == other.shape[-2]).

Time complexity: O(count * (ndim + n * m * p)) where count = size / (n * p)

Space complexity: O(n * m * count)

Returns: New Array with shape (…, n, m) containing the matrix product. Returns None if other is not an Array or if dimensions are incompatible.

This is a convenience wrapper around the Array.__matmul__() operator, similar to NumPy’s np.matmul. It multiplies two Array instances if both inputs are Array with compatible dimensions.

  • b (mininumpy.array.Array) – Right-hand side operand. Must be an Array with dimensions compatible with a (i.e., a.shape[-1] == b.shape[-2]).

mininumpy.array.Array

mininumpy.minilinalg.LU_decomposition(A)[source]

Perform LU decomposition of a 2D Array (matrix) with partial pivoting.

This factorizes a square matrix A into the product of a permutation matrix P, a lower triangular matrix L, and an upper triangular matrix U, such that P * A = L * U.

  • L is a unit lower triangular matrix (diagonal entries are 1).

  • U is an upper triangular matrix.

  • P is a permutation matrix representing row swaps performed during partial pivoting.

Parameters:

A (mininumpy.array.Array) – Input 2D Array (matrix). Must be two-dimensional and square.

Return type:

tuple[list[list[float]], list[list[float]], list[list[float]], int]

Time complexity: O(n^3)

Space complexity: O(n^2)

Returns: A tuple (P, L, U, swap_count) where:

  • P is the permutation matrix.

  • L is the unit lower triangular matrix.

  • U is the upper triangular matrix.

  • swap_count is the number of row swaps performed.

Returns None if the input is not a 2D Array.
